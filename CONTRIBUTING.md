# Panduan Kontribusi

Terima kasih atas minatmu untuk berkontribusi pada dokumentasi Arcadia Online!

## Cara Berkontribusi

### 1. Laporkan Masalah
- Buka tab **Issues** di GitHub
- Jelaskan masalah secara detail
- Sertakan nama file dan baris yang bermasalah

### 2. Perbaiki Dokumentasi
- Fork repository ini
- Buat branch baru: `git checkout -b/perbaikan-judul`
- Lakukan perubahan
- Commit dengan pesan yang jelas
- Buat Pull Request

### 3. Tambahkan Konten Baru
- Diskusikan dulu di Issues sebelum menambahkan dokumen baru
- Ikuti struktur folder yang sudah ada
- Gunakan template yang tersedia

## Aturan Penulisan

### Format File
- Gunakan format **Markdown (.md)**
- Encoding: **UTF-8**
- Line ending: **LF** (bukan CRLF)

### Gaya Penulisan
- Gunakan **Bahasa Indonesia** yang baik dan benar
- Judul menggunakan format `# Judul Utama`, `## Sub Judul`, dst
- Gunakan list untuk poin-poin
- Gunakan tabel untuk data terstruktur
- Sertakan contoh jika memungkinkan

### Penamaan File
- Gunakan angka urut di depan: `01_ProjectVision.md`
- Gunakan underscore `_` sebagai pemisah
- Gunakan CamelCase untuk nama: `ProjectVision`, `CombatSystem`

### Struktur Dokumen
Setiap dokumen harus memiliki:
1. **Judul** — nama dokumen
2. **Ringkasan** — 1-2 paragraf penjelasan
3. **Konten utama** — isi dokumen
4. **Referensi** — link ke dokumen terkait (jika ada)

## Cabang (Branch)

| Branch | Fungsi |
|--------|--------|
| `main` | Dokumentasi stabil |
| `develop` | Pengembangan aktif |
| `feature/*` | Fitur baru |
| `fix/*` | Perbaikan |

## Pertanyaan?

Buka diskusi di tab **Discussions** jika ada pertanyaan.
