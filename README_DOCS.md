# Arcadia Online Documentation V1.0

> **Ini bukan sekadar GDD, tetapi fondasi resmi proyek.**

## Tentang Dokumentasi Ini

Saat V1.0 selesai, kita belum menulis satu baris kode pun, tetapi kita sudah memiliki:

- Visi proyek yang jelas.
- Aturan desain yang konsisten.
- Arsitektur teknis.
- Struktur data.
- Lore dunia.
- Panduan visual.

Dengan fondasi ini, ketika masuk ke Unity kita tidak lagi merancang sistem dari nol, melainkan mengimplementasikan dokumen yang sudah disepakati.

## Struktur Repository

```
Arcadia-Online-Docs/
├── README.md
├── LICENSE
├── CHANGELOG.md
├── CONTRIBUTING.md
├── ROADMAP.md
│
├── docs/
│   ├── 01_GDD/          ← Game Design Document (35 dokumen)
│   ├── 02_TDD/          ← Technical Design Document (14 dokumen)
│   ├── 03_DDD/          ← Data Design Document (13 dokumen)
│   ├── 04_Story_Bible/  ← Kitab Dunia Arcadia (18 dokumen)
│   ├── 05_Art_Bible/    ← Panduan Visual (15 dokumen)
│   ├── 06_Game_Balance/ ← Data Keseimbangan
│   ├── 07_Technical_Reference/ ← Referensi Teknis
│   ├── 08_Project_Management/ ← Manajemen Proyek
│   └── 09_Assets/       ← Daftar Aset
│
├── concepts/            ← Konsep awal & brainstorm
├── references/          ← Referensi eksternal
├── mockups/             ← Mockup UI & layout
└── diagrams/            ← Diagram arsitektur & flowchart
```

## Bagaimana Menggunakan Dokumentasi Ini
